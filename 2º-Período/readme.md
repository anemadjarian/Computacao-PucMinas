# 2º Período
Este diretório reúne os projetos, exercícios e trabalhos práticos desenvolvidos durante o 2º Período do curso de Ciência da Computação na PUC Minas.

- **Nota:** Algumas disciplinas deste período possuem repositórios próprios com códigos completos e documentações detalhadas.

## 📁 Disciplinas 
### Engenharia de Software I (/ES1)
Projetos e documentações voltados para o ciclo de vida de desenvolvimento de software, requisitos, modelagem de sistemas e práticas de engenharia.
### Sistemas Inteligentes (/SI)
Atividades focadas no estudo de dados, modelos estatísticos, inteligência artificial e análise crítica/comparativa de respostas geradas por LLMs.
