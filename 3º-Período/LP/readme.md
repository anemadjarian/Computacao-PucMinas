# Linguagem de Programação
Este repositório contém os trabalhos, relatórios e análises acadêmicas desenvolvidos para a disciplina de Linguagens de Programação.

O foco principal deste módulo é o estudo aprofundado da linguagem Haskell, explorando os conceitos e características fundamentais do paradigma puramente funcional.

## Haskell — Linguagem de Programação
Trabalho completo que cobre os aspectos teóricos e práticos da linguagem Haskell.
## Análise de Artigo — Ambientes de Desenvolvimento para Haskell
Estudo analítico e resenha crítica sobre o artigo "Ambientes de Desenvolvimento Integrado no Apoio ao Ensino da Linguagem de Programação Haskell" (Russi & Charão, 2011).
