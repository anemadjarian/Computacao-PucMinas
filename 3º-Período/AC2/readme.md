# Arquitetura de Computadores II
Este repositório contém as atividades práticas, simulações de circuitos lógicos, projetos em sistemas embarcados e interpretadores desenvolvidos na disciplina de Arquitetura de Computadores II.

## Atividade 01 - Projeto e Simulação de ULA (1 bit, 4 bits e MUX)
Projeto e simulação de uma Unidade Lógica e Aritmética (ULA) utilizando o software Logisim.

## Atividade 02 - Somadores Lógicos e Análise de Tempo de Propagação
Estudo da arquitetura interna de circuitos somadores e análise de atraso em portas lógicas (Carry Propagation Delay).

## Atividade 03 - Aplicações em Arduino (Semáforo e ULA Emulada)
Projetos práticos de hardware e emulação de sistemas desenvolvidos na plataforma Tinkercad com Arduino Uno R3.

## Atividade 04 - Interpretador de Instruções ULA (Java)
Programa em Java responsável por ler um arquivo de instruções de alto nível em formato `.ula` e traduzi-lo para opcodes hexadecimais em um arquivo de saída `.hex`.
