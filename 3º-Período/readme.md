# 3º Período
Este diretório reúne os projetos, exercícios e trabalhos práticos desenvolvidos durante o 3º Período do curso de Ciência da Computação na PUC Minas.

- **Nota:** Algumas disciplinas deste período possuem repositórios próprios com códigos completos e documentações detalhadas.

## 📁 Disciplinas 
### Arquitetura de Computadores II (/AC2))
Atividades voltadas para a organização de sistemas computacionais, hierarquia de memória, conjunto de instruções, concorrência e programação em baixo nível/assembly.
### Linguagens de Programação (/LP)
Projetos e estudos focados em paradigmas de programação, análise léxica e sintática, semântica de linguagens e implementação de conceitos fundamentais da computação.
