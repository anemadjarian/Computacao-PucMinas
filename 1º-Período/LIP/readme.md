# Lab. de Iniciação à Programação

Ao longo da disciplina, foram desenvolvidos diversos exercícios com o objetivo de compreender e aplicar os principais conceitos da linguagem C. 

## Estruturas condicionais
Utilização de comandos como `if`, `else` e `switch` para controlar o fluxo de execução do programa com base em condições lógicas.

## Estruturas de dados
Manipulação de diferentes formas de armazenamento e organização de informações, como vetores, matrizes e estruturas (`struct`).

## Modularização
Divisão do programa em funções, promovendo a reutilização de código, a organização e a manutenção do software.

## Estruturas de repetição
Implementação de laços de repetição, como `for`, `while` e `do...while`, para executar um conjunto de instruções de forma iterativa.
